# Music Listening

I've collected 31 listens from my Airbuds history for Dear Data 100. I've recorded an ID, date, assigned time, song, artists and source order for each listen.

I've tested my sketch in Processing and checked that all 31 records appear and that hovering over a disc shows its details. I still need 69 more listens to reach 100.

## Data

I've kept repeated plays as separate records and left out entries I couldn't read. I've assigned times between noon and 2 p.m. where exact times were unavailable; these are not recorded listening times. My sample covers only part of my listening history.



## Run

I run `DearDataMusic/DearDataMusic.pde` in Processing's Java mode with `listening.csv` in the adjacent `data` folder. I press S to save an image.
